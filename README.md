# Fundsroom Full Stack Developer Case Study - ERP/CRM System

This repository contains the full stack ERP/CRM system designed and developed for the Fundsroom Full Stack Developer Case Study.

## Architecture

- **`backend/`**: Node.js, TypeScript, Express.js REST API with PostgreSQL database, JWT Authentication, Role-based Access Control (RBAC), and Atomic Inventory Control.
- **`frontend/`**: React application (to be connected with backend API).

## Backend Quick Start

```bash
cd backend
npm install
npm run build
```

See [backend/README.md](file:///Users/ankur/fundsroom-erp/backend/README.md) for full setup instructions, database schema details, REST API contract, and Postman testing guide.
